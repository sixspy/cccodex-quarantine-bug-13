**抓取批次 → 坏件入隔离舱 → 复核放行 / 回炉重抓 → 隔离对账**

## 超时晋升（甲路：不可变快照）

回炉任务执行超时即落**失败档**，脏件退回待复核不再悬挂；仓管对超时任务做**一次性晋升**，
超时当刻把任务键与晋升指纹封进只读快照表 `timeout_promotions`（`UNIQUE(job_id)` 串行，双人同抢只成一个）。
详情/回炉/对账/设置四块只读同一套快照引用，不双开乙路独立账册：

- 详情列表亮**晋升徽标**与快照落点；回炉侧亮**超时档（超时失败）**并挂同一快照号；
- 对账卡挂超时摘要（超时/已晋升/悬挂）与闸门状态；设置页只展甲路快照晋升口径；
- 徽标与超时档/落点拧花、指纹不合、有超时未晋升时，**闸门拦截继续清洗**（回炉执行前过闸）。
